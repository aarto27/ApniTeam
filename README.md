# ApniTeam

Modern fantasy sports mobile app built with Expo + React Native.

This repository is being rebuilt from the existing Instant11 product behavior with a cleaner architecture, improved UI, stronger state handling, and reduced API amplification.

## Stack

- Expo
- React Native
- Expo Router
- Supabase
- TypeScript
- TanStack Query

## Principles

- One canonical match lifecycle
- Server-authoritative contest joins and wallet mutations
- Deduplicated network requests
- Realtime patches instead of unnecessary full refetches
- Deterministic fantasy scoring
- Feature-based architecture
- No secrets committed to source control
